# Исправления проблем развертывания

## ✅ Исправлено

### 1. Проблема с коммитом в команде `set-deploy`

**Проблема:** 
```
error: pathspec '2025-11-25' did not match any file(s) known to git
error: pathspec '12:42:51' did not match any file(s) known to git
```

**Причина:** Сообщение коммита с двоеточием и пробелами неправильно экранировалось на Windows.

**Решение:** Использован компонент `Process` Symfony для надежного выполнения команды git commit.

### 2. Проблема с vite на сервере

**Проблема:**
```
sh: 1: vite: Permission denied
```

**Причина:** Отсутствие прав на выполнение для vite в `node_modules/.bin/`.

**Решение:** 
- Контроллер развертывания теперь автоматически устанавливает права на `node_modules/.bin`
- Используется `npx vite build` для гарантированного выполнения
- В `package.json` уже используется `npx vite build`

## 🔧 Что нужно сделать на сервере

### Быстрое исправление проблемы с vite:

```bash
cd ~/avito.siteaccess.ru/public_html

# Установите права на node_modules/.bin
chmod -R +x node_modules/.bin

# Теперь соберите проект
npm run build
```

Или просто используйте:
```bash
npx vite build
```

## 📝 Тестирование

### Локально:

```bash

php artisan set-deploy --message="Тестовый коммит с двоеточием: 12:00:00"
```

Команда должна работать корректно с любыми символами в сообщении коммита.

### На сервере:

После следующего развертывания через `set-deploy`, проблема с vite должна решиться автоматически, так как контроллер теперь:
1. Устанавливает права на `node_modules/.bin`
2. Использует `npx vite build`
