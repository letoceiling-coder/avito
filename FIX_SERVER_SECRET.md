# Исправление ошибки "Секретный ключ не настроен на сервере"

## ⚠️ Проблема

Ошибка: **"Секретный ключ не настроен на сервере"**

Это означает, что на сервере еще старый код, который требует `DEPLOY_SECRET` в `.env`.

## 🔧 Решение

Выполните на сервере:

```bash
cd ~/avito.siteaccess.ru/public_html

# 1. Добавить секретный ключ в .env
echo "DEPLOY_SECRET=123123123" >> .env

# 2. Проверить, что ключ добавлен
grep DEPLOY_SECRET .env

# 3. Очистить кеши (чтобы .env перечитался)
php8.2 artisan config:clear
php8.2 artisan cache:clear

# 4. Проверить, что ключ читается
php8.2 artisan tinker
# В tinker выполните:
# env('DEPLOY_SECRET')
# Должно вернуть: "123123123"
# Выйдите: exit
```

## ✅ После исправления

После добавления `DEPLOY_SECRET` в `.env` на сервере выполните локально:

```bash
php artisan set-deploy --message="Тест после установки ключа" --secret=123123123
```

## 📝 Важно

- Используйте **тот же** секретный ключ локально и на сервере
- После добавления ключа **обязательно** очистите кеши: `php8.2 artisan config:clear`
- Ключ должен быть в `.env` файле, а не в `config/app.php`
