# Исправление ошибки 419 (CSRF Token)

## Проблема

При выполнении `php artisan set-deploy` возникала ошибка:
```
Статус: 419
Ответ: Page Expired
```

## Причина

Роут `/deploy` находится в `routes/web.php`, который по умолчанию защищен CSRF middleware в Laravel. POST запросы без CSRF токена отклоняются с ошибкой 419.

## Решение

Роут `/deploy` исключен из CSRF проверки в `bootstrap/app.php`, так как у нас уже есть собственная защита через `DEPLOY_TOKEN`.

### Изменения в `bootstrap/app.php`:

```php
$middleware->validateCsrfTokens(except: [
    'deploy',
]);
```

## Безопасность

Роут `/deploy` защищен через:
1. **DEPLOY_TOKEN** - если указан в `.env`, проверяется в контроллере
2. **IP фильтрация** - можно добавить через middleware (опционально)

## Рекомендации

Для дополнительной безопасности на сервере добавьте в `.env`:

```env
DEPLOY_TOKEN=ваш_секретный_токен_здесь
```

Токен будет автоматически отправляться с запросом и проверяться на сервере.

## Тестирование

После исправления команда должна работать:

```bash
php artisan set-deploy --message="Тестовый коммит"
```

Запрос должен успешно обрабатываться без ошибки 419.
