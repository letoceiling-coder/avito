# Важно: Обновление кода на сервере

## Проблема

Ошибка 419 все еще возникает, потому что изменения в `bootstrap/app.php` еще не применены на сервере.

## Решение

### Вариант 1: Обновить код на сервере (рекомендуется)

Выполните на сервере:

```bash
cd ~/avito.siteaccess.ru/public_html

# Обновите код из git
git pull origin master

# Очистите кеш конфигурации
php artisan config:clear
php artisan cache:clear
```

После этого команда `set-deploy` должна работать.

### Вариант 2: Использовать роут в api.php (временное решение)

Если не можете обновить код на сервере сейчас, можно использовать роут `/api/deploy`:

1. Переместите роут в `routes/api.php`
2. Обновите URL в команде на `http://avito.siteaccess.ru/api/deploy`

Но это требует изменений в коде команды.

## Проверка

После обновления кода на сервере проверьте:

```bash
# Локально
php artisan set-deploy --message="Тест после обновления"
```

Должно работать без ошибки 419.

## Текущая конфигурация

В `bootstrap/app.php` уже настроено исключение CSRF:

```php
$middleware->validateCsrfTokens(except: [
    'deploy',
]);
```

Но эта конфигурация должна быть применена на сервере!
