# Быстрый старт: Автоматическое развертывание

## Команда для локальной разработки

```bash
php artisan set-deploy
```

Эта команда:
1. ✅ Добавит все изменения в git
2. ✅ Создаст коммит
3. ✅ Отправит в git репозиторий
4. ✅ Выполнит POST запрос на `http://avito.siteaccess.ru/deploy`
5. ✅ Сервер автоматически обновит проект, установит зависимости и подготовит к работе

## С параметрами

```bash
# С указанием сообщения коммита
php artisan set-deploy --message="Исправлена ошибка"

# С указанием URL сервера
php artisan set-deploy --url="http://avito.siteaccess.ru/deploy"

# Комбинированно
php artisan set-deploy --message="Обновление" --url="http://avito.siteaccess.ru/deploy"
```

## Настройка безопасности (опционально)

Добавьте в `.env` на сервере:

```env
DEPLOY_TOKEN=ваш_секретный_токен
```

Токен будет автоматически отправляться с запросом.

## Что происходит на сервере

При получении POST запроса сервер автоматически:
- Обновляет код из git
- Устанавливает PHP зависимости (composer)
- Устанавливает Node.js зависимости (npm)
- Собирает фронтенд
- Выполняет миграции БД
- Очищает и пересоздает кеши
- Очищает логи

## Проверка работы

После выполнения команды вы увидите:
- Статус операций git
- Ответ сервера с результатами развертывания
- Детальный вывод всех операций
